# JetBrains---Analytics-for-ML-Feature-Usage-in-IDEs


This repository contains one Python notebook for the task from **JetBrains Analytics for ML Feature Usage in IDEs** internship.

JetBrains IDEs understands the current context in the editor to provide accurate auto-correction. This notebook investigated user data to analyze how developers use code-completion features.

The Python notebook includes code, outcomes, and visualization. Underneath each block of code, there is explanation and interpretation. By the end, recommendations are proposed based on findings.
